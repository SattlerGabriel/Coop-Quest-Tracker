# Coop Quest Tracker
SPT + Fika mod that shows a panel on the main menu comparing your active quests with every other player online on the server.

For each online player, each of your active quests is shown as:
- **Shared**: they have it active too
- **Missing**: they can accept it but haven't yet
- **Locked**: they can't accept it yet (prerequisites, level, trader loyalty)
- **Completed**: they've already finished it

# Installation
Every player needs the client plugin; the server mod goes on the machine running the SPT server

Just extract the zip in the game folder brah

# Usage
The panel appears on the main menu and refreshes each time you return to it (or press **Refresh**). Drag it by the title bar. **F7** shows/hides it. In the F12 menu you can change the key, turn the panel off, resize it with the **Window scale** slider (0.5×–2.5×), and make it taller with the **Window height** slider (150–1200 px) when many players are online.
